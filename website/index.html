  1. 使用 Android ARM64 手机下载安装包。建议 Android 11 及以上；其他系统版本尚未全面验证。
  2. 按系统提示允许本次安装，打开「好好输入法」，完成启用与切换输入法。
  3. 新安装默认使用本地词典。云翻译是可选项，未配置时不影响中文输入。
  4. 26 键新增离线整句纠错，帮助纠正漏键、多键、邻键和字母颠倒；不是语义改写，同音词和九键错按仍有局限。
  5. 保留紧凑布局、三套配色和词本复习；腾讯云发音暂未开放。

测试版不等于稳定版。本版沿用已确定的新公开签名，后续更新保持同一包名与签名。官网原 20260921 包及旧签名内测包不能直接覆盖升级。请先保留旧应用，备份词本和自定义配置后再迁移，不要直接卸载丢失数据；已使用新签名 20260923 包的用户可以覆盖更新。
