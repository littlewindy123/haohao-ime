# 好好输入法官网事实基线

> 核验日期：2026-08-28
> 权威来源：https://github.com/littlewindy123/haohao-ime

- 好好输入法是面向中文用户的 Android 双语输入法实验项目，基于 Trime 与 Rime。
- 英文短释义仅添加在展示层，不改变中文候选顺序、索引或提交行为。
- 英文默认在候选稳定 300ms 后显示；美式 IPA 可选且默认关闭。
- 词典随应用内置，候选查询不需要网络权限；数据损坏时隐藏英文，不影响中文输入。
- 固定词典包含 121,165 个唯一简体词头，可对外概括为「12 万+中文词头」。
- Android API 36、x86_64 模拟器已通过安装与基础交互验证；真机兼容性与触屏体验仍在验证。
- GitHub 当前没有正式 Release，因此官网不得提供 APK 下载或暗示已有稳定版。
