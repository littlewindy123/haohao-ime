# 个人词本与复习规则

## 范围与入口

「我的单词」保留最近遇见、我的收藏和正在学习。「好好学习」首页提供我的词本、薄弱词、学习统计、我的学习四个固定入口，句子入口保留，日历归入统计，计划设置与备份归入我的学习。无词时先选内置词书或导入；已有用户优先继续原会话，修改模式从下一轮生效。轻复习与每日计划共享同一份学习数据。候选点击仍只提交中文；查看释义、收藏和加入学习需要用户主动操作。不提供账号同步、排行榜、自动学习提醒或缺勤惩罚。

本说明依据当前 Kotlin、Room、资源和测试实现，不对记忆效果作保证。完整数据边界见[隐私说明](../../PRIVACY.md)。

## 历史、收藏与义项

最近记录上限为 100 个词，遇见次数只表示符合记录条件的输入次数，不能推断记忆程度。关闭记录保留已有数据；密码及禁止个性化学习的输入框依编辑器标记排除记录。

学习条目由「中文释义 + 规范化英文义项」共同标识。同一个中文可以保存多个英文义项，不因英文相同而猜测不同中文可以合并。英文去重键去除首尾和多余空白并转为小写；独立的 `displayEnglish` 保留确认的大小写。英文仍最多四词、32 个字符；学习中文释义最多 512 个 Unicode 字符，输入历史和候选词头的 32 字限制独立不变。来源为 `offline`、`cloud` 或 `import`（用户导入），音标可为空。详情的「修正英文大小写」只能修改同一去重键的展示文本，保留学习进度。

保存的是用户确认的快照。已有义项再次遇到云端刷新或其他来源时，不覆盖其英文、来源、音标和学习进度；新释义必须另行主动保存。没有可靠英文时不能加入学习。

收藏和学习是两个独立标记：收藏不自动加入学习，移出学习不取消收藏。词本成员关系也构成保留条件，未收藏、未学习的导入词不会被自动清理。批量暂停保留内容与排程，影响该义项所在的所有词本。旧版按中文保存的收藏继续显示，升级不会把它们自动转为学习义项。

## 词本分组与内置词书

个人词本可新建、改名、删除、搜索；每页最多 50 个义项，支持批量加入、移动、移出分组以及加入学习或暂停。删除词本只删除关联，没有其他分组的词进入「未分组」，词义和进度保留。点击词条打开现有详情，完整多义参考与已保存回忆题面分别显示。同一义项加入多本书只补关联，不覆盖来源、大小写、音标、收藏、学习状态或排程。加入学习不会修改当天已经冻结的目标或活动会话。

三本内置词书使用 ECDICT 固定提交 `bc015ed2e24a7abef49fc6dbbb7fe32c1dadaf8b`，源 CSV SHA-256 为 `1a6947e04785db63613a92e14903cdae7954f7e84860b10e68e5c7cbb3f9c3cf`。按 `bnc`、`frq` 最小有效正整数及英文排序，基础高频取前 1000；四级、六级分别筛选 `cet4`、`cet6` 标签。实际为 1000／3846／5406 词，共用 6379 个义项，不宣称覆盖最新版官方大纲。

每个英文选第一条完整、含中文且符合长度约束的原始释义行，规范化转义换行和空白，不截断或补造答案。无有效释义的条目不收录。通过 `python app/dictionary/learning/build_wordbooks.py --source <已校验的本地CSV>` 重建；Android 构建、选书和导入不下载词库。独立只读资源 `wordbooks.bin`（GZIP 内容，避免 Android 自动解压重命名） 为 202062 字节，哈希与数量记录在同目录的 `wordbooks-manifest.json`，运行时按该哈希校验。选书保存内容快照，后续资源更新不覆盖本机答案，资料许可沿用已有说明入口。

## CSV 与粘贴导入

先新建或选定目标词本，再通过系统选择器导入 UTF-8（可带 BOM）CSV，或粘贴两列制表符文本。CSV 支持引号内逗号、换行和双引号转义，第三列音标可选；提供模板并可在预览中交换中英列顺序。预览分别统计新增、已存在、文件内重复、无效项，错误清单按原始起始行号列明原因并分页。只有用户确认后才导入有效项；文件内重复保留第一条有效项，同义项只补分组。

输入上限 16 MiB、十万条，UTF-8 解码或 CSV 语法损坏时整份拒绝，不静默截断。解析在后台进行，写入在单个 Room 事务完成，重复提交被阻止；页面旋转保留预览和执行状态。确认前取消不导入，事务失败不留下部分义项或成员。用户主动创建空词本是独立操作，取消随后的导入不会删除该词本。导入临时文件位于应用私有缓存，成功、取消或退出后删除，不自动上传。

新词来源如实标为 `import`，默认只保存，完成后可主动加入学习。旧内容与进度完全保留；暂停、导入和恢复共用学习代次防止旧页面写入。单词更新使用 Room `@Upsert`，不能恢复为 SQLite `REPLACE`：后者会触发外键级联，导致评分或撤销时意外丢失分组。

## 复习与每日计划

轻复习每轮最多 5 个词，先选到期词，再选从未回答的新词；暂停学习的词和未到期的旧词不进入新会话。每日计划默认关闭，默认每天 5 个新词、10 个复习词；可设置的新词范围为 1–50，复习词范围为 1–100。轻复习与每日计划都支持英译中、中译英、拼写练习和混合回忆，默认英译中。

在「好好学习」或计划设置选择模式，未完成的会话继续原模式，新选择从下一轮生效。英译中先显示英文，中译英与拼写先显示已保存的中文；后两种模式揭晓前隐藏英文、音标、发音和例句。所有模式都必须主动揭晓或核对后才能评分。

拼写接受大小写、多余空格和直弯撇号的等价形式，但不忽略缺字、连字符或词间空格。核对仅比较当前已保存义项，不查询或猜造同义答案。拼错或主动查看答案时只能选「忘记了」「有印象」；UI 和存储事务同时阻止「记住了」，避免错误推进间隔。输入草稿和首次核对结果持久保存，揭晓后不能修改草稿重新冒充首次答对。切换下一张卡清空草稿和结果；撤销恢复原草稿与结果。

混合模式在创建卡片时按队列位置与既有复习次数分配方向，方向随卡片保存。即使词本只有一个词，跨轮也会轮换英译中、中译英、拼写；同轮遗忘重练保持原方向。翻面、重建与撤销不会随机换题。

首屏使用统一任务摘要，显示未完成会话的剩余卡片数，或实际可复习的最多 5 个词；没有到期任务时显示下次时间，空词本说明如何加入第一个词。摘要订阅数据库变化，并每分钟刷新时间。每日计划开启后进入今日概览，设置通过独立入口修改；「保存设置」不开始新会话。当前轮明确显示模式与方向，计划修改从下一轮生效。

复习入口按钮只显示「开始复习」「继续复习」或「上轮复习」，数量保留在上方摘要。答题页用工具栏标明会话、卡片外显示进度、卡片内提示回忆方向；计划修改的生效说明放在计划设置页，避免答题时重复提示。

轻复习和计划按本地日期共享答题记录，同一天已经回答的义项不会重新进入新会话；轻复习也消耗对应的新词或复习配额。选择「继续」可以主动再练剩余合格义项，放宽本轮的日配额扣减，但仍不重复抽取当天已答义项，也不提前抽取未来到期词。

必须先查看答案，再提交「忘记了」「有印象」「记住了」。反馈规则如下：

| 反馈 | 阶段变化 | 下次安排 |
| --- | --- | --- |
| 记住了 | 前进一阶段，最高为第 5 阶段 | 依次为 1、3、7、14、30 天；之后继续按 30 天复习 |
| 有印象 | 保留当前阶段 | 1 天后 |
| 忘记了 | 回到第 0 阶段 | 1 天后，并在本轮稍后额外练习一次 |

这里的「天」是从回答时间起的 24 小时间隔，不是自然日零点。系统时钟倒退时，排程不会早于上次回答时间。最高阶段表示较长复习间隔，不表示永久掌握。

「忘记了」插入的同轮练习最多一次，位置在剩余队列的两个词之后；不足两个时放在队尾。它不再增加本轮完成词数、日配额或 `reviewCount`，也不因答对而推进间隔；若再次忘记，会重置阶段并从此次练习安排一天后复习。

## 会话与数据契约

Room 的 `word_learning_state` 持久保存当前队列、答题方向、完成数量及答案显示状态。每张卡有独立 token；显示答案和回答均校验当前 token，并在事务内保存。重复点击、旧页面回调或重试不能重复计分；未显示答案时的反馈被拒绝。

两个入口优先恢复已有未完成会话，因此从轻复习转入每日计划时不会并行建立另一套队列。重新创建页面可恢复当前卡和已显示答案。会话内被移出学习或删除的义项会跳过，不计作完成。

每轮允许撤销最近一次评分，包括遗忘后的同轮练习。`undoJson` 保存评分前的学习状态、队列、答案显示状态及该次插入日记录的日期。评分与撤销都在 Room 事务内完成；撤销只移除该评分新增的日记录，跨日不误扣当前日期。撤销保留后续收藏或大小写修正，并更换恢复卡片的 token，拒绝旧回调。新评分替换快照，新建一轮、移出相关义项或清空全部使撤销失效；清空历史保留学习和撤销。退出重进同轮可继续撤销，完成页也提供入口。

数据库仍为 `haohao_vocabulary.db`，位于 `Context.noBackupFilesDir`。Room 保留完整的 1→2→3→4→5→6→7→8 升级路径：1→2 新增学习表；2→3 新增 `displayEnglish` 和 `undoJson`；3→4 新增句子表；4→5 新增每日目标及反馈事件；5→6 添加可空的 `reviewMode`；6→7 给正式事件添加可空的 `mode`、`spellingOutcome`，并新增独立加练状态与事件表。旧事件的模式、拼写结果保持未知，不根据历史评分补造拼写错误。旧方向由 `reverse` 回退，旧会话 JSON 的新字段都有默认值。迁移不重写已确认义项、排程、打卡、句子和撤销记录，不使用破坏性重建。

最近历史淘汰和「清空历史」只操作旧历史表，保留已保存的收藏与学习义项。确认「清空历史、收藏和学习进度」后，在事务内清空历史、义项、日记录和会话；每日计划设置保留。词本清理不等于清理 Rime 用户词典、剪贴板或手动导出的配置。

词本数据库不进入 Android 自动备份；云翻译缓存另在云备份和设备迁移 XML 中排除。卸载或清除应用数据会删除本地词本。当前发音由 `WordSpeech` 与 `SpeechPlayback` 按用户点击播放；需要网络且未授权时先走现有同意流程，缺配置、过期和播放失败分别提示。多模式复习不新增网络请求或自动发音。离开页面停止播放并释放回调，离开输入界面会取消待处理云请求，但已经发送的数据无法撤回。

## 学习统计与个人概览

3.3.23 继续增加 7→8 非破坏性迁移：新增 `wordbooks` 和 `wordbook_members`，既有已保存义项归入稳定 ID 为 `personal-default` 的「我的词本」，旧学习表字段保持原值。删除词条通过外键同步清理成员关系；删除分组不会反向删除义项。默认个人词本也可改名或删除，后续 v1 恢复按稳定 ID 补回缺失的默认分组。

「学习情况」按今天、近 7 天、近 30 个自然日切换；柱状图包含没有记录的日期，每日新学/复习词数沿用唯一日记录，不把同轮重练重复记作新词。反馈次数来自未撤销事件，允许包含重练；两种指标不能混为同一口径。逐项数据可展开阅读，图表也有完整文字描述。

「回忆表现」只使用同一义项具有前次记录的跨日复习，按 1 天、2–3 天、4–7 天、8–14 天、15 天以上分组，展示选择「记住了」的次数与样本量。排除撤销、重练和没有前次记录的数据；零样本不画成 0% 的观测点。这是本人的自评观察，不是个人遗忘曲线预测，也不宣称实现第三方记忆模型。

「复习安排」列出现在待复习和今起 7 天内尚未到期的词数，直接使用当前排程；不含未学新词，后续答题会改变安排。「我的学习」展示真实学习天数、累计/连续打卡、反馈次数、在学与收藏词数、进入长间隔的词数以及已有印章。没有虚构学习时长、账号同步、等级或购买额度。

拼写草稿随本地会话保存，不作为输入历史记录或新增网络请求。它与学习数据库一起受原有清理、卸载和无系统自动备份规则约束，也包含在用户主动导出的学习备份中。

## 薄弱词与独立加练

学习首页的「薄弱词」提供「最近总忘」和「经常拼错」。按最近 30 天、未撤销、非同轮重练的记录统计，遗忘或核对拼错累计至少两次进入对应列表；最后两条相关记录连续成功后移出。拼写核对正确、核对错误、直接揭晓分别记录为 `CORRECT`、`WRONG`、`REVEALED`，历史未知使用空值。直接揭晓不算成功，也不凭空算一次拼错。删除、暂停学习的义项不参与抽题。

每轮按失败次数、最近失败时间排序，最多十词。两个列表各按 50 词分页，页面重建保留页码，翻页不改变抽题顺序。「最近总忘」使用混合回忆，并按独立加练次数轮换方向；「经常拼错」固定拼写。使用 `learning_practice_state` 和 `learning_practice_events`，可与未完成每日计划并存，草稿、完成页和单步撤销独立持久化。加练评分和撤销不写正式事件、日记录、每日目标或词的排程字段，因此不产生打卡或消耗正式额度。同轮重练仍最多一次，完成页列出需要再练的词，不自动开始下一轮。

拼写差异用有界编辑距离标示漏字、多余字符和替换字符，仅作解释；正确与否仍由既有 `spellingMatches` 严格规则决定。直接揭晓或拼错不能选择「记住了」。

## 学习备份格式与恢复

入口为「我的学习 → 备份与恢复」，使用 Android 系统文档选择器导出、读取普通 UTF-8 JSON。文件上限 16 MiB，总记录上限十万条；格式、版本、字段、唯一键及会话撤销关联全部校验通过后才显示预览。损坏、不支持的未来版本和超限文件不写入数据库。没有新增账号、云同步或自动上传；用户应妥善保管包含个人内容的导出文件。

格式版本独立于 Room 版本，当前为 `format: "haohao-learning"`、`version: 2`，继续读取 v1。v1 的词在恢复或合并时加入默认个人词本；旧版应用必须拒绝 v2，不生成隐式丢失分组的降级文件。顶层字段如下：

| 字段 | 内容 |
| --- | --- |
| `exportedAt` | 备份生成时间，Unix 毫秒 |
| `words`、`sentences` | 确认的词句、收藏和学习状态 |
| `books`、`memberships` | 词本稳定 ID、名称、内置来源标识，以及词本与义项的关联；v1 可缺省 |
| `settings` | 每日计划、模式、正式会话及撤销快照 |
| `days`、`tasks`、`events` | 唯一日记录、冻结的每日目标、正式反馈（含已撤销记录） |
| `practiceState`、`practiceEvents` | 独立加练会话、草稿、撤销及反馈 |

输入历史、剪贴板、密钥、翻译缓存、隐私开关和句子自动保存开关均不在文件内。会话 JSON 保存模式、题目方向、拼写草稿和结果；历史事件允许关联已经移除的词，不能因此清除合法历史。

「完整恢复」先用 `AtomicFile` 保存本机回滚副本，再在同一个 Room 事务中替换学习表。副本保存在禁止自动备份的目录，成功恢复后仍提供一次回滚；下一次完整恢复替换该副本，回滚成功或清空全部词本数据后删除。回滚会撤回恢复后新增的学习内容，因此执行前明确提示影响。输入历史、输入法偏好和隐私开关不变。

「仅合并内容」只插入不存在的联合键，重复项完全保留本机内容和进度。新增词保留收藏、加入学习状态及内容，但阶段和复习次数归零，复习时间为空；不导入计划、历史评分或会话。词本按稳定 ID 合并，同名不同 ID 保留并自动区分名称，只补缺失的成员关系。完整恢复和本机回滚覆盖分组表；重复合并不会增加重复项。

恢复前使旧句子异步保存票据失效；完整替换时更新学习代次，统一更换活动卡片和撤销 token 及关联事件引用，拒绝旧页面评分、草稿和撤销回调。恢复事务出错或取消时原学习数据保留。备份页面用保留的 ViewModel 管理执行状态，旋转时继续显示正在处理，避免重建重复执行。用户取消系统选择或确认弹窗不修改学习数据。

## 本地输入与联网边界

新装候选模式为 `LOCAL_ONLY`，本地缺释义不自动请求网络。升级继续沿用现有明确同意的配置。云翻译由手机直接访问用户配置的服务商，没有新增中转服务器或输入记录训练上传。`release` 构建始终继承空共享密钥；`embedInternalCloudSecrets` 只影响明确指定的开发调试包，回归测试包也始终禁用共享密钥。

离线二进制词典在后台映射和校验，主线程首次查询不会等待完整词典加载；准备完成后刷新当前释义展示。近期 256 个词的查询结果使用有界缓存，中文候选顺序和点击范围不变。云缓存也在后台加载，序列化由单线程写入器处理，避免整份缓存编码阻塞中文输入。学习记录使用 Room 挂起事务，与候选提交分离。

Rime 的就绪调用与启停共用挂起互斥锁，最后一个客户端退出后，异步清理会重新检查是否已有新客户端。这样可避免旧客户端的延迟清理关闭新客户端正在使用的原生调度器。会话有效性按实例判断，不能只凭同名会话仍存在就接受旧回调。候选回归检查允许编译词典位于用户目录或当前共享预编译目录，仍校验全部排名和两次运行之间的文件修改时间。
