# 好好学习：今日任务与本地统计

## 实现

- 版本 3.3.14 / 20260929，Room 4→5 增量迁移；不改变单词答案、原复习间隔、句子本或候选输入。
- 首页“好好学习”与每日计划进入统一学习页，含今日任务、词本、句子本、月历和独立统计页。
- 开启计划后，首次开始（包括快速复习）冻结当日目标；默认新学 5、复习 10，已有配置保留。新加入的词和修改后的数量不扩大当日目标。
- 快速复习可完成目标词；目标之外的反馈记作额外学习。未启用计划仍记录实际学习，不生成打卡。
- 忘记后的重练完成前不打卡；撤销、移出学习在事务内更新任务。空目标、全部移除和历史计数不能凭空打卡。
- 逐次事件以卡片 token 幂等记录时间、本地日期、评分和新学／复习／重练类型。撤销事件保留撤销标记，不参与统计。评分分布含重练，不是“记忆率”。
- 跨日会话保留，剩余卡片并入当日任务；昨天的未完成任务不追溯补签。历史日期按写入时固定，不随当前时区改写。
- 原按天记录不再裁剪为 31 天，但已经被旧版本裁掉的数据不能恢复。旧记录显示学过，不推定历史打卡或评分。
- 数据留在 noBackupFilesDir 中的现有私有数据库。清空学习数据同时清除事件和打卡，独立句子本保留。

## 验收方式

单元测试使用项目现有 Kotest runner。数据测试使用隔离包的临时数据库；UI 测试只写隔离包固定 learn 词条，截图仅绘制 Activity 内容，不截聊天或通知。

```powershell
./gradlew.bat :app:testRegressionUnitTest :app:assembleRegression :app:assembleRegressionAndroidTest -PbuildABI=arm64-v8a -PembedInternalCloudSecrets=false
```

新增 `LearningProgressPolicyTest`、`LearningProgressStoreTest` 和 `LearningProgressUiTest`；旧版本 1/2/3 迁移测试也接入 4→5 迁移。

本轮不提交、不推送、不部署官网、不替换官网 APK。日常包不自动安装；本地产物沿用现行固定签名，无共享云密钥。用户确认继续后，UI 验收在独立 regression 包内执行，不操作日常词本或聊天。
